# Security Policy

MeshtasticPass is early-stage software. Security behavior and interfaces may
still change as the project develops.

Do not post vulnerability details, credentials, channel keys, private node
information, or personal mesh traffic in a public issue. This repository does
not currently publish a private security-reporting address. Until a private
reporting method is available, open a minimal public issue asking for a private
contact path without including technical vulnerability details or sensitive
data.

If you accidentally publish a credential or channel key, revoke or rotate it
immediately. Removing it from the latest commit or deleting an issue does not
make an exposed credential safe.
